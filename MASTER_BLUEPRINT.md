# Master blueprint — architecture

```
crates/kavach-host/          the whole engine; ZERO dependencies, builds with --offline
  probe.rs                   what the machine is (cpu, ram, gpu, disk)
  exec.rs                    child processes: allow-list, timeout, rlimits, process-group kill
  path.rs                    path guard — every file write goes through it
  sha256.rs                  hashing, no crates
  json.rs                    JSON writer
  store.rs                   durable index: projects, checkpoints, task ledger, notes, models
  builder.rs                 requirements → plan → scaffold → model code → security → verify
  security.rs                secret / eval / URL scanning; high findings fail the build
  runtime.rs                 loopback-only client for Ollama and OpenAI-compatible servers
  models.rs                  model catalogue, quantisation, device-aware recommendation
  agents.rs                  agents/skills/commands/rules parsed, mapped to local tools
  agents_builtin.rs          GENERATED by scripts/embed-agents.py — do not hand-edit
  install.rs                 model install: licence gate + SHA-256 before adoption
  export.rs                  copy a project out
  commands.rs                the 27-command surface (JSON in, JSON out)

apps/desktop/                Tauri 2 shell + static HTML/JS UI (no bundler)
crates/kavach-host/assets/app/   the template embedded into every generated project

agents/ skills/ commands/ rules/  43 definitions ported from everything-claude-code
examples/stocklab/          a worked example of generated output (not the product)
docs/ECC-LOCAL-PORT.md      how the Claude-oriented architecture was ported to local models
scripts/                    verification, packaging, bootstrap, checks
```

## Data flow

```
prompt ──extract_requirements──▶ Requirements
       ──build_plan───────────▶ Tasks (dependency ordered)
       ──scaffold─────────────▶ GeneratedFile[]
       ──write (path guard)───▶ project dir
       ──model code (opt)─────▶ accepted only if tests still pass, else rolled back
       ──security::scan───────▶ findings (high severity fails)
       ──run_tests────────────▶ node permission model + network preload guard
       ──ledger───────────────▶ task states + evidence, change note, lesson note
```

## Invariants — do not break these

- The host crate has **no dependencies**. Adding one ends offline builds and the audit story.
- Every write goes through `path.rs`. No `std::fs::write` with a user-supplied path.
- The webview gets no filesystem, shell or network permission; it may only call registered
  commands, and `build.rs` restricts that list to the ones that exist.
- A generated app must pass its own tests before it is delivered.
- The store writes temp-then-rename, keeps a `.bak`, and refuses a "verified" task with no
  evidence.
